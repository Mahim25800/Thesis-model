General notes for generation

Build every chart and table with a script that reads the named JSON file directly. Values in this guide are for cross-checking only, since file schemas can drift.

Only Figures 4.2 to 4.6 need the two Gradio apps running and screenshotted.

Figures 3.2 and 4.14 need real extractor or inference runs to produce intermediate images, not just JSON.

Save each output under its exact number, for example fig_4_7_synthbuster_auc.png or table_3_3_training_config, so it drops into the matching placeholder without renumbering.

Use the same values for Figures 4.9, 4.11 and 6.1 as for Tables 4.3 and 4.4 so charts and tables never disagree.
